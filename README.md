# StudioForma — Interior Design Portfolio Website

A complete static multi-page portfolio website for a fictional interior architecture studio. Designed to run directly on GitHub Pages with no build step.

## Highlights
- 30+ HTML pages
- Responsive navigation and layouts
- 12 detailed project case studies
- Project category filtering
- Before/after comparison slider
- Interactive project cost estimator
- Lightbox image viewing
- Scroll reveal and animated statistics
- Demo contact form with client-side success state
- Local SVG artwork (no remote image dependencies)
- SEO titles/descriptions and custom 404 page

## Publish on GitHub Pages
1. Create a new GitHub repository.
2. Upload the contents of this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

## Structure
- `index.html` — homepage
- `projects.html` — filterable portfolio
- `*-house.html`, etc. — project case studies
- `assets/css/styles.css` — all styling
- `assets/js/main.js` — interactions
- `assets/images/*.svg` — local project artwork

All names, locations, budgets and people in this demo are fictional portfolio content.
